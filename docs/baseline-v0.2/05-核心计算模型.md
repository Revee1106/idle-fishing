# 05｜核心计算模型（01—08）

状态：八个模型结构已确认；系数、概率、时间边界、配置值待联合模拟。下列公式表示已讨论认可的计算结构，不是完整的可执行数学规格；未定义的参数必须在配置结构设计和模拟前明确。所有修正保留计算精度，最终按业务规定转换；无非法负数、NaN或无穷大。

## 0. 模型依赖及随机契约

角色有效属性 → 位置准入 → 抛竿及等待 → 咬钩候选及替代事件 → 鱼种抽取 → 个体重量和体色 → 捕获对抗计划 → 结果及准备 → 经验与经济结算。等待中的环境变化按时间节点推进；属性与装备在抛竿时快照，实际咬钩时锁定环境、鱼种、个体和对抗计划。在线与离线、模拟器与正式游戏使用相同规则。已经抽样的结果不可因重登重抽；所有结算幂等。

## 1. 有效角色属性与边际收益

```
A = A_base + A_allocated + A_equipped_rod
F(A,K) = A / (A + K), K > 0
F(A,D,K) = A / (A + K * D), D > 0
```

属性点可无限增长，但作用趋近有限上限。不同属性、同一属性的不同作用均可独立设置K及上限。力量、技巧采用相对于鱼类难度的曲线；敏捷、感知使用有界时间缩减；幸运对不同随机对象分别设置最大权重倍率。广告不计入有效属性。设备属性先相加再计算收益，物理性能独立。等级本身不参与捕获或概率。暂定五项初始10点、每级5点自由属性，例示K=100不构成冻结值。

通用时间缩减结构：`T = T0 * (1 - Rmax * F(A,K))`，结合最终时间边界。

通用相对权重结构：`M = 1 + (Mmax - 1) * F(A,K)`，使用归一化而非直接增加概率百分点。

## 2. 作钓准入

设位置水平距离D、垂直深度H，单位米；鱼竿上限D_rod、H_rod，鱼线总长L_total，预留比例r。

```
L_required = sqrt(D^2 + H^2)
L_effective = L_total * (1 - r)
admitted = regionUnlocked && positionExists && positionDiscoveredIfHidden
           && equipmentOwnedAndEligible
           && D <= D_rod && H <= H_rod && L_required <= L_effective
```

预留比例暂定10%，不消耗鱼线。准入是确定性判定，角色属性、承载/拉力、稀有度、天气、广告均不参与。运行条件（鱼饵、仓库等）独立检查。真实物理不逐帧模拟；这里采用直线几何简化。不同地区配置实际存在的位置，不默认笛卡尔积。装备不足不自动改位置。

## 3. 钓鱼时间

### 3.1 时间组成

```
T_total = T_cast + T_bite + T_reel_basic + T_fight + T_prepare
```

使用现实秒，世界昼夜加速不影响动作时钟。鱼种抽取、个体生成、结算无独立耗时。

抛竿：`T_cast = max(T_min, T0(rod,D) * (1 - R_agi * F(AGI,K_cast)))`。基础动作由鱼竿及距离决定，不额外随机。

准备：由上次结果配置基础时间（断线/过载可较长），敏捷缩减，存在最低时间。失败不产生维修损失。

基础收线：`T_reel_basic = (T_operation + L_required / V_base) / (M_agi * M_rod)`。敏捷及鱼竿收线效率生效，使用实际位置所需线长，不是整根线总长。

额外对抗：基础时长由个体难度决定，力量及控鱼改善，技巧/敏捷不直接缩短额外挣扎。示意结构 `T_fight = T_fight_base * (1 - R_str * F(STR,D,K)) * M_control`；若控鱼已计入D，不在同一耗时路径重复修正。可为0，有合理上限。

### 3.2 等待期望与随机需求

```
T_bite_mean = T_base(position) / (M_activity * M_bait)
              * M_perception * M_equipment
```

活动倍率合并鱼群活跃、天气、昼夜、环境事件；鱼饵基础吸引力影响等待。感知按有界收益缩短等待，竿灵敏度和线信号先合并再计算信号收益。幸运、敏捷不直接影响等待。鱼种相对权重与总体咬钩速率分开，不以幸运加权后的总权重当咬钩速率。

进入等待时抽一次无量纲随机需求Q，建议使用三角分布 `Triangular(a, mode, b)`。暂定示例(0.3, 0.8, 1.9)，均值1。环境固定且无广告时 `T_bite = Q * T_bite_mean`（未触及时间边界）。

动态累计：`P(t) = integral[0,t] 1/T_bite_mean(u) du`，达到Q时咬钩。广告有效时速率乘独立广告倍率。环境变化按边界分段积分，Q不重抽、已累计进度不清零。有效鱼池为空时不生成鱼，可等待环境恢复，超时空竿；不得除以零、强制生成不存在的鱼或强制触发意外物品。

### 3.3 广告速率、边界与恢复

广告效率定义为执行速率 `V_ad = 1 + B`，不是耗时直接减少B。常量期间 `T_actual = T_normal / V_ad`；四个阶段都受速率影响，不改变抽样概率和相对失败节点。中途开始/到期，已执行进度保留，只调整后续速率。广告现实时间到期，世界时间不加速。

抛竿、等待、基础收线、准备有正的最终下限；对抗可为0、有最大耗时；完整尝试具有合理上下限。时间上下限与广告、动态进度及空池超时的具体组合尚待细化。失败可提前结束但经过正常抛竿、等待和准备；手动取消无失败经验及有效事件尝试。退出、离线耗尽、恢复见03。

## 4. 鱼种概率

### 4.1 候选及权重

候选由地区、位置、实际咬钩时环境、明确条件及鱼饵适配决定。临时洄游可以显式增补种群。任何明确禁止、缺失种群或零偏好均不能被幸运/倍率下限复活。

```
W_i = D_i * B_i * H_i * E_i * L_i
P_i = W_i / sum(W_j)
```

D_i为位置种群基础权重；B_i为鱼饵鱼种偏好；H_i为隐蔽性修正；E_i为环境分布修正；L_i为幸运修正。所有权重非负，总权重大于0时归一化。稀有度标签不额外乘基础稀有概率惩罚；不同地区可以使稀有鱼当地相对常见。

隐蔽性：`H_i = 1 - R_H * C_i * (1 - I)`。警觉性C_i和隐蔽性I归一化0～1；高隐蔽减少警觉损失，不提高额定拉力。R_H为最大权重损失比例。

环境：`E_i = clamp(M_time * M_weather * M_event, E_min, E_max)`。明确禁止优先于clamp，同类事件不重复。整体活跃度、分布、重量/体色分别配置。

幸运：`L_i = 1 + (Mmax_rarity - 1) * Luck/(Luck + K_rarity)`。普通可为1，稀有度越高可有更高倍率，具体待平衡。示例上限1/1.3/2/3/5。权重倍率不等于最终概率倍率，归一化改变其他鱼的占比。

### 4.2 抽取节点

抛竿锁定属性、装备、位置；实际咬钩时读取环境。替代型意外鱼获先判（最多一个，总概率有上限）；未替代才抽鱼种。额外型事件按结算条件独立处理。鱼种概率为正常鱼种抽取分支的条件概率，不含捕获成功或事件替代概率。

鱼饵偏好继承：默认→食性→鱼种→可选地区覆盖（替换）。候选总权重为0不抽鱼；允许空竿，独立事件必须满足自身条件。免费基础饵在常规位置应至少有适配种群（有效可捕获配置是经济保底）。

## 5. 个体生成

### 5.1 重量等级与区间

每种鱼独立定义最小/最大整数克重量及六个互斥区间：微型、小型、普通、大型、巨型、纪录级。等级边界不统一按最大重量百分比划分。种群可修改各等级权重或禁止某等级，不改变全局理论最大值。

```
W_grade_i = Q_i * D_i * B_i * L_i * E_i
P_grade_i = W_grade_i / sum(W_grade_j)
L_i = 1 + (Mmax_i - 1) * Luck/(Luck + K_i)
```

Q_i为鱼种基础权重，D_i为种群修正，B_i为鱼饵重量偏好，E_i为环境重量修正。抽中等级后再生成具体重量。幸运、巨物饵及事件默认只修正等级，不再次修正区间内部。禁止等级不复活。

区间内使用可配置幂函数：`w = w_min + (w_max - w_min) * U^alpha`，U为均匀随机数，alpha>0。alpha=1均匀，>1偏下限，<1偏上限。最终整数克生成需保证区间互斥、最大值具有非零可达概率；离散算法待明确（09）。不通过事后乘重量突破范围。不设置重量保底。

### 5.2 体色

```
W_color_i = C_base_i * D_i * L_i * E_i
P_color_i = W_color_i / sum(W_color_j)
```

鱼种配置允许体色及基础权重，种群、幸运、特殊环境分别修正并有限叠加；设置特殊体色合计概率上限。体色和重量在给定配置下独立随机，不互相影响；体色单一、不增加捕获难度、可增售价及少量经验。无体色保底。零允许性优先；正常体色须有合法配置。

生成鱼种、重量、体色后锁定个体，失败不解锁图鉴，成功生成正式持有鱼获及档案。相同重量不刷新纪录，理论最小/最大值均可实际达到。个体重量及基础对抗属性不因重新登录、天气、广告而改变。

## 6. 捕获判定

### 6.1 个体对抗属性

持续挣扎拉力Fs、额外爆发拉力Fb、脱钩难度Dh。单位拉力N，重量使用一致单位比值。

```
Fs = S0 * (w/w_ref)^alpha_s
Fb = B0 * (w/w_ref)^alpha_b
```

脱钩难度使用独立重量曲线，不必单调增加；同种同重量基础属性一致，不附加随机隐藏战力。重量连续影响对抗，不按重量等级突变。

### 6.2 力量与脱钩

```
Ds = (Fs/F_ref) / M_control
F_str = STR / (STR + K_s * Ds)
P_strength = P_max * (1-F_str)^gamma
P_hook = P_base * (1-R_skill * Skill/(Skill+K_h*Dh)) * M_control_hook
```

力量不足为概率风险，无固定属性准入门槛；物理允许时低力量也可有成功机会。技巧降低脱钩，不直接降低持续对抗时间。控鱼改善力量对抗和脱钩，可在不同效果使用不同参数，但同一效果不可重复修正。所有概率限制于[0,1]。

### 6.3 物理负载与操作失误

```
F_peak = Fs + Fb * (1 - R_buffer)
F_actual = F_peak + F_operation_error  # 仅发生失误时追加
physical_pass = F_actual <= C_rod && F_actual <= C_line
P_error = P_error_base * (1-R_error * Skill/(Skill+K_e*De))
```

持续阶段检查Fs，必经爆发检查缓冲后峰值，失误节点检查附加负载。延展性只缓冲爆发，不降低持续负载、不提高额定承载。鱼竿与鱼线独立硬约束；正常必经负载已经超限，则理论成功率为0，力量、技巧、幸运、广告不能突破。两个装备同时超限优先记录较低额定上限对应原因，相同上限固定顺序待明确。操作失误不必然失败，仅当附加负载造成超载才失败。

### 6.4 节点计划

咬钩后一次性计算完整收线/对抗时长、持续负载检查、必经爆发节点、力量不足风险、脱钩风险、操作失误风险及各自潜在时间点；概率风险独立抽样。实际最早失败决定结果；其余未发生的节点不执行。成功必须完成全部必经节点。无额外总成功率抽样，无每秒重复抽样。广告只推进执行速度，不改变节点相对位置。节点可按完整对抗进度比例定义，具体范围待定。

玩家反馈四大类：力量不足、脱钩、断线、鱼竿过载。底层断线/过载细分客观及操作型，以支持策略诊断及失败经验判定。

理论分析（在独立风险前提下）：正常物理条件不通过时 `P_success=0`；通过时 `P_success=(1-P_strength)*(1-P_hook)*(1-P_load_error)`。只有失误足以超载才计入P_load_error。该概率只供策划和失败经验评估，不再次决定结果。

## 7. 经验与成长

```
XP_normal = XP_base_species * clamp((w/w_ref)^alpha_xp, min_xp_mult, max_xp_mult)
XP_catch = XP_normal + XP_color
XP_fail = floor(min(XP_cap, XP_normal * R_fail * F_progress * F_capability))
XP_next(L) = ceil(A * L^B)
```

基础经验综合鱼种稀有与难度，不再重复乘等级/稀有/难度。体色常规经验少量。成功追加可配置的全局首次鱼种、地区首次鱼种、首次特殊体色奖励，可叠加。全局每鱼种最大重量刷新少量奖励；大型/巨型/纪录级首次里程碑奖励一次，跨级补齐。首次建立纪录由发现覆盖；最小、地区、体色纪录和同重量不额外奖励。实际纪录每克刷新；常规纪录XP比较上次奖励重量（首捕建立基准），达到累计突破门槛才奖励；阈值与奖励数值待模拟。

失败经验无正数保底。客观物理不可捕获、空竿、手动取消直接0；即使提前脱钩也必须检查正常必经路径物理可行。可获得经验的失败以无额外奖励XP为基础、比例上限及绝对上限、有效执行进度与理论捕获能力修正。用执行进度而非现实耗时；不得因故意失败成为最优升级策略。

无限等级以幂函数为主，必要时再调整分段曲线；初始A/B待定。完整保留溢出，多级升级逐级发放自由属性点及资格。无地区经验衰减、等级压制、广告直接经验倍率。离线升级照常，未分配点不生效；离线会话上限下一次更新。

## 8. 经济模型

```
Price = Price_base_species * (w/w_ref)^alpha_price * M_color
Net_value_hour = 3600 * E[net_value_per_attempt] / E[actual_duration]
E[net_value_per_attempt] = P_success * E[price | success]
                           - bait_reference_cost + E[event_gold]
```

价格默认次线性增长，鱼种可独立配置，体色溢价独立；不再乘纪录、等级、地区、稀有度等额外倍率。取整和最低价待定。期望公式针对全部成功鱼出售的策略，P_success需计入正常鱼分支及实际捕获成功；真实现金余额必须使用实际出售及购买流水。每小时经验类似计算 `3600*E[XP]/E[duration]`，不能忽略失败提前结束或价格与成功的相关性。

装备回本辅助计算：`purchasePrice/(netIncomeNew-netIncomeOld)`，仅适用于正收益增量。特殊用途装备不强制经济回本。

重置（n为本次累计金币重置序号）：`C_reset(n)=min(C_max,C0*R^(n-1))`。免费/广告不增加n；无等级因素、次数不清零，固定封顶。暂定首次1000、倍率2，封顶待模拟。

自动购买：`available=max(0,balance-reserve)`，`quantity=min(batch,floor(available/unitPrice))`，支持部分批次；余额不得为负。免费饵及拟饵独立处理。

离线广告金币最终修订：`eligible=max(0,newFishAutoSaleGold-consumedBaitReferenceValue)`，`adGold=min(cap,eligible*rate)`。只计本会话自动出售新鱼及实际消耗饵参考价格（免费获付费饵也按参考价，基础饵0），不计购买时点、旧鱼、成就、事件、其他广告或留存鱼估值；不再次扣现金。每会话一次。细则见06。
