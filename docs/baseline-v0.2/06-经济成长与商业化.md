# 06｜经济、成长与商业化

## 1. 经济闭环（已确认）

唯一常规货币为金币。鱼获出售是主要产出；随机事件、成就和自愿广告为补充，未来比赛可提供奖励。捕获本身不直接发放鱼售价对应金币。没有钻石、付费货币、玩家交易、动态市场或NPC订单（首版）。

消耗包括普通竿线/拟饵购买、消耗饵、部分地区一次性解锁、永久仓库及水族馆扩建、重置属性；装饰及后续改装按版本加入。无耐久维修、金币衰减、生活费、入场费、强制消耗、鱼缸维护或持续经营支出。后期可以大量积累金币；不要求所有玩家收支平衡。主要持续消费是鱼饵和属性重置，收藏及专项挑战可为经济流带来新的目标。

## 2. 鱼获定价及出售

以鱼种参考重量下基础售价、实际重量幂函数、体色倍率相乘，默认次线性重量增长，可为鱼种独立配置。稀有及难度在基础价考虑，不重复乘；纪录、地区、时间、等级、幸运、收藏时长不直接影响售价。特殊体色主要提供收藏价值，溢价不可破坏经济成长。参考公式见05。

单条、批量、自动出售、水族馆出售统一价格，不收手续费。未出售个体按出售时最新版本规则；历史交易不追溯。鱼个体可留存，鱼获估值不等于金币余额。出售不删除图鉴/历史纪录、不重复发经验。

## 3. 装备与其他永久投入

装备独立定价，不将各属性相加得到统一战力或价格。经济型装备可参考增量净收益回本时长，专项型装备不要求正向回本。初步回本目标（实际作钓时长）：初始成长0.2～2h、初级2～8h、中级8～24h、高级24～72h、顶级经济型72h以上，均需模拟。装备永久唯一，不出售、不重复购买、不要求前置装备全买。常规装备不直接以广告获取特殊幸运竿。

地区费用一次性，池塘、溪流、热带河流、隐秘山湖初步无金币解锁费用；水库、海岸需要金币，实际阈值待定。仓库容量按鱼数、逐级永久扩容，容量价格待定；水族馆鱼缸按生态、单体规格及空间配置定价，扩建是自愿收藏需求。

## 4. 鱼饵与经济策略

基础饵免费无限；常规付费饵在合适条件下可以提高经济收益，针对性和高级饵提供独特目标价值，可以亏损，拟饵一次购买长期使用。消耗型饵抛竿扣除，失败/空竿/取消不退。不能因高级价格就保证更高净收益。

自动补货可开关，仅当前已解锁可买饵，允许设置金币保留量和购买批次；部分批次允许，金币不得为负。补货失败按玩家预设切基础饵或暂停，不擅自买其他饵。金币储备只约束自动操作，不限制主动购买。初始装备、地区、基础饵永久保留，存在稳定正收益配置；锁定鱼占满仓库时需要玩家清理或扩容，不强行出售。

## 5. 经验与成长

成功捕获常规XP为主要来源，额外包括首次鱼种、首次地区鱼种、首次特殊体色、最大重量突破及重量等级里程碑；特殊体色常规XP少量。可配置事件和成就的一次性XP。出售、购买、收藏、广告、主动取消不发经验。失败经验允许0，必须满足物理可行性，并受比例、绝对上限、实际执行进度与理论捕获能力限制。

无限等级，升级需求幂函数为主，后期大幅增加。固定自由属性点、未分配不生效，不自动提升五项属性。等级可解锁地区、商店/使用资格、永久离线时长，不直接加成功率、售价或XP。经验溢出保留；离线升级正常，本会话离线额度不增加。初始8h最高24h，不看广告可永久达到24h。暂定等级1/10/25/50/80对应8/12/16/20/24小时，待模拟。

## 6. 属性重置（最新确认规则）

重置返还全部已分配自由点，不影响等级、经验、初始属性及装备属性，无终身次数限制，下一次抛竿生效。

金币费用随累计金币重置次数指数递增并封顶，**不再随等级增加**。首次费用暂定1000金币、倍率暂定2：1000、2000、4000、8000……达到封顶后固定。封顶100000仅为演示；目标约成熟经济流2～4小时净收益，待模拟。永久累计金币重置次数不因升级、每日刷新或换地图清零；只有成功金币重置增加计数。新手免费与广告免费不增加计数；初期免费次数/条件待定，广告免费暂定每日一次。禁止离线自动重置。

## 7. 广告商业化（已确认边界）

无任何内购，不加入强制视频、插屏、横幅或付费皮肤。仅玩家主动选择的激励视频，失败或未完成不扣除玩家既有收益，不设置广告专属成就、特殊鱼种、特殊鱼竿、隐藏地图、幸运值、保底或直接比赛分数。无广告玩家可体验全部常规内容并获得所有特殊竿和永久24小时离线额度。

| 权益 | 规则 | 数值状态 |
|---|---|---|
| 钓鱼效率 | 独立执行速率，四个时间阶段均加速；不直接改概率、捕获、XP或金币单价 | 暂定每次30分钟现实时间、每日最多6次，追加有效时长不叠加倍率；具体倍率待定 |
| 离线额度 | 延长下一次离线会话，永久+临时总量不超过24小时 | 单次扩展量及次数待定 |
| 离线金币 | 本次符合条件正净收益额外金币，封顶，每会话一次；原收益先发 | 倍率、封顶、领取窗口待定 |
| 鱼饵补给 | 已解锁且正常可取得的饵，少量，越高级数量越少；基础饵永远免费不需要广告 | 高级饵每日最多一次，按单种或共享次数待定 |
| 属性重置 | 替代金币重置，无累计金币重置次数增加 | 暂定每日一次 |

不做仓库临时广告扩容（首版）。广告效率在线离线一致，现实时间到期即时调整速率，不将整次钓鱼锁定在旧广告倍率。广告实际权益不叠加出多倍概率，不作为自动触发行为。广告凭证、防重放、跨日口径等由后续技术设计确定。

## 8. 离线广告金币计算（最新修订）

仅计本离线会话中新捕获并自动出售的鱼，减本会话实际消耗鱼饵参考价（即使此前购买或广告免费获得，按消耗时配置价计；基础饵0）。不计旧鱼出售、保留鱼估值、事件金币、成就金币、其他广告。正净额乘奖励倍率且封顶；负数按0。参考价扣减仅用于奖励基数，不再扣真实金币。一次会话只领取一次，不复制鱼获、经验或图鉴进度。

## 9. 经济数据口径

实际金币流水=真实入账（出售、事件等）减真实支出（购买、扩容等）；作钓经济价值=鱼获产出估值减实际消耗饵参考价值，可用于研究策略；广告基数是第8节定义的独立口径。三者不可混用，不重复扣除买饵及耗饵。统计金币累计产出、消耗分类、装备购入、重置次数、鱼饵消耗、库存及估值，支持离线报告和P1研究报告。
