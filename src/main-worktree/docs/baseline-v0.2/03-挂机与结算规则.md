# 03｜挂机与结算规则

## 1. 状态与时钟（已确认）

一次钓鱼包含抛竿、等待咬钩、基础收线与额外对抗、重新准备四个耗时阶段；抽鱼种、个体生成及结算为逻辑节点，不另计耗时。成功、失败、空竿及替代型意外鱼获均有明确结算分支。P0任一有效本地存档仅有一个作钓任务；跨设备唯一性待云端阶段。

- 抛竿时锁定地区位置、鱼竿、鱼线、鱼饵、有效属性及相关版本；消耗型鱼饵在抛竿时扣除一次。
- 进入等待阶段抽取一次随机需求；天气、昼夜、环境事件与广告速率的变化按实际时间分段推进，不重新抽样、不清空累计进度。
- 咬钩时读取当时的环境，确定鱼种、重量、体色与对抗计划；锁定后不因环境改变、关闭游戏或重登而重抽。
- 对抗风险只抽一次，执行最早实际失败节点或完成全部对抗；结算不重复抽总成功率。广告加速不能跳过必经节点。
- 成功后完成经验、图鉴、纪录、成就、鱼获处理等；失败按原因结算有限经验及统计；随后准备下一次。重复执行同一结算不得重复发放。

## 2. 在线与离线

初始永久离线额度8小时，最高24小时，可随等级永久提升；广告可以为下一次离线会话增加额度，但总额度不得超过24小时。具体等级节点及单次广告扩展量待定。

退出时当前行为继续执行；重新登录恢复同一状态，不重新抽鱼、不重置等待、不重复消耗。离线额度耗尽时冻结作钓进度，超出额度的现实时间不产生收益。回到游戏继续原进度。世界时间仍按实际时间推进，恢复时按当前世界环境继续，暂停期间不产生个人收益；见12。

会话开始锁定当时可用最大离线额度；离线期间升级正常发放经验、属性点及解锁资格，但永久离线时长增加只在下一次会话生效。离线不会自动加点、重置属性、购买或更换装备、切换地区及主动收藏。自动购买当前鱼饵和自动出售按预设策略继续。

同样初始状态、随机状态、配置及时间线下，在线与离线必须得出相同结果；不采用独立离线收益表或经验折扣。应以时间节点推进，不要求逐秒模拟。广告速率到期及环境边界必须分段处理。

## 3. 配置变更

更换地区、鱼竿、鱼线、鱼饵、距离或水层会取消当前未完成的行为，并按新配置重新开始；已耗鱼饵不退。先校验新配置，非法指令不取消原尝试；提示玩家主动选择，不能自动切换其他位置。购买装备、管理鱼获等与当前作钓无关的动作不改变当前行为。角色加点/重置从下一次抛竿生效。

每地区记忆最后配置；手动作钓预案可记录地区、竿线饵、距离、水层、自动出售与补货策略（多预案P1）。旧预案失效时保留但不直接启动。主动取消没有失败经验、有效失败成就或重要事件有效尝试进度。版本更新后新行为重新校验准入，已锁定行为的跨版本规则见11—12。

## 4. 自动补货

玩家可选是否自动购买当前已解锁且可购买的消耗饵，配置最低金币储备、批次购买目标。余额允许不足完整批次时部分购买；不可突破保留量或负余额，不擅自购买其他付费饵。无法补货时按玩家预设使用免费基础饵或停止。切换备用基础饵后保留原首选设置，须玩家手动恢复；免费饵无限，拟饵无持续消耗。补货前检查运行许可，见12。

## 5. 仓库与自动出售

- 容量按鱼类个体数量，而非重量；金币永久扩容，有限上限配置。
- 支持单条、批量、自动出售；出售规则可按重量、重量等级/稀有度等维度设置，支持手动锁定；锁定鱼绝不自动出售。
- 自动保留规则包含首次鱼种/体色、纪录、指定鱼种/重量、稀有等；自动保留优先于自动出售。每鱼种或体色Top N、复杂组合条件属P1。
- 仓库满可预设停止、出售新鱼、智能出售未受保护鱼。手动锁与有效保留均不可被自动出售覆盖；无法安全容纳新鱼时，保存一条已结算待处理鱼并暂停。智能出售低价值优先，同价按捕获时间（再以ID稳定排序属实现建议）；详见12。
- 自动出售成功鱼仍正常获得经验、图鉴、纪录与成就，不能因出售省略成功捕获记录。水族馆转入、取回不重复发放经验。水族馆只手动管理。

## 6. 挂机报告与统计

离线报告应记录有效钓鱼时间、暂停及额度损失、尝试/成功/各类失败/空竿、鱼获、鱼饵消耗及补货支出、金币实际收入、经验和升级、首次鱼种/体色、纪录、重要发现、成就。区分鱼获估值和实际金币收入，突出可指导装备及策略调整的原因。

全局统计包括生涯捕获数量、重量、尝试、失败类型、时间、金币流水、鱼饵、装备使用、地区及环境、收藏与成就。研究报告（P1）可比较可比条件下的实际历史样本，不展示精确内部概率或将观察值误称真实概率。

## 7. 账户、存档与版本

P0本地用户文件、三槽备份、版本迁移、恢复、删除二次确认及本地幂等；设备时间只能做基础异常检查，不能强防作弊。P1云绑定、云存档、跨设备恢复与可信时间；P2服务端权威结算，竞争玩法依赖相应可信机制。

保留历史鱼重量、体色、捕获时间、纪录档案；新版本的重量/概率变化只影响未来生成，不重新结算历史收益。未售鱼按出售时价格，装备新配置在后续行为使用；新增成就可以依历史统计补发一次性奖励。已售普通鱼的明细可在汇总且满足审计/留存要求后清理，重要档案不能丢失。具体数据结构及事务见10—12；本机首次成功加载新版本为切换边界，保留旧版补算能力。
