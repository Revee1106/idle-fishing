# 12｜运行状态机与结算事务

状态：业务规则已确认；伪代码、字段命名及未明确的同级排序、精度等仍为实现设计。以本卷为03、10的运行契约补充；数值以05/06及后续模拟为准。

## 1. 状态与身份

应用状态：INITIALIZING → MIGRATING（需要时）→ OFFLINE_SETTLING（需要时）→ RUNNING；后台为BACKGROUND；故障恢复RECOVERING；无法安全推进为ERROR。与钓鱼阶段分离。浏览页面不停止钓鱼。所有业务写指令（含时钟、生命周期、广告）串行进入应用服务，异步IO不能旁路修改状态。

| 钓鱼状态 | 入口 | 退出及行为 |
|---|---|---|
| IDLE | 未开始或主动取消 | 合法Start后预检并抛竿 |
| CASTING | 创建AttemptId、锁快照、扣饵 | 达到工作量后进入WAITING |
| WAITING | 抽一次等待需求 | 达需求抽鱼/替代事件；空竿可直接结算 |
| FIGHTING | 锁鱼类个体及对抗计划 | 执行最早失败或全部必经节点后成功 |
| SETTLING | 有确定结果 | 统一事务结算，进入PREPARING或暂停 |
| PREPARING | 已结算 | 准备完成后预检下一轮 |
| PAUSED | 额度、待处理鱼、缺饵等 | 保留可恢复阶段和进度，满足条件后继续 |

AttemptId在正式抛竿生成、全局在本档内唯一；取消不复用ID，不返饵、不发XP、不计有效失败/重要事件尝试。FishId在成功后成为正式持有身份，候选阶段不更新图鉴。快照包含地区、位置、竿线饵有效配置、属性、等级、版本、工作量及进度、随机需求、候选鱼及对抗节点，见10。不可在恢复或结算时重抽。逻辑阶段不额外消耗现实时间；持续负载、爆发及风险按05，不额外抽总成功率。

## 2. 指令与快照

| 指令 | 处理 |
|---|---|
| ChangeRegion/Equipment/Bait/Position | 先校验新配置；合法才取消旧尝试并按新配置启动，已消耗饵不退 |
| Allocate/ResetAttributes | 修改持久状态，下次抛竿生效 |
| PurchaseEquipment | 只增加拥有状态，不自动换装 |
| StopFishing | 取消当前尝试，不把主动停止伪装成失败 |
| SetSale/RetentionPolicy | 下一次尚未处置的鱼获生效 |
| SetReplenishPolicy | 下一次补货检查生效 |
| SellFish/MoveFish/Expand | 不改变当前已锁个体及对抗计划 |
| AdSpeed | 改变剩余阶段执行速度，不改变概率或节点 |

指令非法时不产生部分写入，特别是不得取消正在进行的有效尝试。暂停冻结作钓进度而不冻结世界时间；无个人事件或资源收益。玩家重新上线从原进度继续，使用当时环境；已锁鱼/对抗不改变。未完成待处理鱼时禁止再抛竿。

## 3. 同刻事件

时间区间建议半开[start,end)，先结清到边界的进度，再应用边界事件。以下大类顺序已确认：

1. 结清前一时间区间的阶段进度。
2. 更新昼夜、天气和区域事件。
3. 更新广告权益与版本切换状态（不覆盖现有尝试快照）。
4. 处理已到达的咬钩、对抗节点；失败与成功同时到达时失败优先。
5. 完成已到达的捕获/空竿/替代事件结算。
6. 处理离线截止及暂停条件。
7. 处理玩家指令。
8. 检查并启动下一次尝试。

当刻咬钩按新环境抽样；当刻广告到期不撤销前段进度；离线截止恰好成功仍结算，不补货、不扣下一份饵。客观负载超过竿线上限不可成功；同时超载先较低上限，等上限固定顺序尚需明确，具体多风险同刻排序见09 D02。时间精度、同刻队列次级排序、零时长事件防循环需实现前确定；禁止由JS对象遍历偶然决定。

## 4. 原子业务结算

统一事务不是数据库事务，而是构造一致候选状态后一次提交。流程：

- 校验AttemptId及结果，确认未结算；成功建立正式鱼获及不可变档案；失败/空竿走对应分支。
- 以结算前历史判断首次发现、纪录、保护条件，更新统计及档案。不要在更新后重新判断首次导致丢奖励。
- 处理个人事件、发现与软保底、捕获/失败/首次/纪录经验；不重复抽样。再按保护和出售策略处置鱼获。
- 处理经验溢出升级、成就连锁、奖励和资格，使用统一事件队列。一次性奖励以唯一claimKey去重；异常循环阻止不安全结算。满足付费地区条件不自动支付解锁。
- 将金币、鱼饵、鱼获归属、经验、记录、随机数、时间游标、结算ID、报告累积一并提交，禁止分离写入。
- 普通鱼获允许批量保存，但内存业务事务始终原子；关键结果与离线检查点必须持久化。完成后进入准备/暂停。

发奖与消费具有唯一键：抛竿扣饵以AttemptId绑定；捕获结算以AttemptId唯一；成就/发现/里程碑以条件键；广告以AdRequestId及目标会话报告键。删除普通明细不能提前删除其防重放依据，具体安全裁剪见D14。重要操作持久化成功后再确认最终结果。提交错误或重启不从中间某一子系统继续发奖，应加载最近一致状态。

## 5. 仓库及自动处置

优先级：手动锁 → 启用的首次/体色/纪录等自动保留 → 指定鱼种/重量等保留 → 自动出售 → 默认保留 → 容量溢出。保留优先，手动锁不得自动覆盖。新鱼的首次/纪录判定基于本次结算前历史，后续是否追溯保护规则待D07。

| 溢出策略 | 行为 |
|---|---|
| 满仓停止 | 满时不启动新尝试；正在捕获且需要保留时使用待处理槽 |
| 自动出售新鱼 | 新鱼未受保护时可直接出售 |
| 智能出售 | 从现有未保护鱼优先出售低价值者，同价优先较早捕获；同价同时间稳定ID排序为实现建议 |

若新鱼不能安全入库且不可自动出售，保存一条待处理鱼、正常结算XP/图鉴/纪录/成就、暂停。不得强卖受保护鱼，不得丢弃，不得再捕获第二条待处理鱼。待处理拥有独立归属；玩家可手动出售、移入有空位仓库或直接放入适配鱼缸，不复制、不再次发XP/纪录奖励。处理后满足条件才恢复。已售或转移的鱼不改变历史。

## 6. 自动补货与启动原子边界

上一轮捕获/自动出售/事件成就全部结算 → 准备结束 → 检查运行许可、离线剩余、待处理和仓库 → 校验地区、位置、装备与鱼饵适配 → 检查库存 → 必要时按保留金币及批次数量部分购买 → 锁定配置、扣饵、创建尝试。

运行许可必须在自动补货前检查；已经到截止或暂停不得买饵。推荐补货与新尝试同一逻辑提交，防止只扣金币不记录库存。补货失败按预设FREE/STOP；切基础饵后保留preferredBait，effectiveBait改为基础饵，玩家手动恢复。无合法基础饵位置不得擅自换地区/位置；具体提示及暂停规则需D10落实。免费饵不消耗，拟饵永久。

## 7. 离线会话

会话字段：sessionId、startedAt、allowanceSnapshot、deadline、settledUntil、settlementTarget、adExtension、reportAccumulator、adClaimStatus。开始时额度锁定（初始8h最高24h），升级永久额度下次生效。离线实际经过时间受deadline限制，暂停后的时间不累积为可用额度。游戏世界按现实2小时=游戏24小时继续；额度外无钓鱼及个人事件收益。

补算目标不得超过会话截止时间；分批推进事件节点，检查点提交全部业务状态、时间与随机位置；在未提交片段崩溃后，从最后有效检查点确定性重算。旧会话、截止和已锁目标不可因补算退出重置。只有安全完成并恢复在线后，新的正常退出才创建新会话。目标锁定后到真正恢复在线之间的时间归属及前后台重入细节应在D13测试确定，不得凭空发新额度。报告基于已提交结果，不重复发放报告中的收益。

离线金币广告只按符合条件的本次新鱼自动出售收入扣消耗参考价正净额，封顶一次；普通余额以实际买卖流水为准。跨会话抛竿与售鱼成本归属及领取窗口仍待D13确认。

## 8. 广告事务与时钟

广告请求状态：CREATED → SHOWING → COMPLETED → REWARDED，未完整观看CANCELLED，错误FAILED。AdRequestId绑定权益；重复成功回调只发一次。广告完成的本地记录与实际发奖标记不能分别造成重复收益。效率追加时间、下次离线扩展、金币报告、饵补给、免费重置按06；广告重置不增加金币重置次数。奖励是否完整观看依真实SDK可用回调，模拟不能证明平台资格。客户端突然退出可能丢失未持久化成功回调，不能承诺百分百恢复或强防作弊。

现实设备时间用于会话和广告，前台单调计时推进，世界时钟12倍。检测回拨时禁止负时间和重复离线区间，不能刷新已领取权益；时钟恢复后按有效边界继续。正常故障和恶意篡改区分；巨大前跳、跨日配额固定时区、前台单调时间与逻辑时钟映射待D12/13精确化。

## 9. 异常与验收

当前存档坏→扫描备份；全坏→不自动覆盖；配置不合法→阻止运行；迁移失败→保留旧档；重复指令→按键拒绝重复发奖；写入结果不确定→重新确认有效revision；快速操作/广告/生命周期→串行队列。版本切换见11。

| ID | 断言 |
|---|---|
| FSM-01 | 完整循环、空竿及替代分支合法 |
| FSM-02 | 对抗中退出再入，鱼与风险节点相同 |
| FSM-03 | 非法换装保留原任务及饵 |
| FSM-04 | 合法换饵取消，不退饵且无失败XP |
| FSM-05 | 加点和重置下次抛竿生效 |
| FSM-06 | 广告到期前进度保留，风险不变 |
| FSM-07 | 同刻环境变更后咬钩，结果稳定 |
| FSM-08 | 截止同刻成功结算，不再补货/抛竿 |
| TX-01 | 同AttemptId重复结算无额外变化 |
