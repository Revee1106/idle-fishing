# 08｜数值模拟与验收

状态：模拟方案已确认，验收数值是初步目标而非已经达标的结论。尚未实施任何真实模拟，不存在已验证的数值结果。

## 1. 核心引擎与模拟器

正式游戏与独立模拟器复用同一核心规则引擎：八个模型、时间状态机、经验经济、事件及相关结算。模拟器负责输入场景、自动决策、时间推进、批量统计和报告；正式客户端负责玩家交互、平台集成和表现。不能另写一套近似收益模型并以其结果代替核心引擎验收。模拟器不需要美术、完整UI、微信登录或真实广告接口。

## 2. 三种运行模式

| 模式 | 目的 | 行为 |
|---|---|---|
| A 固定配置 | 比较具体属性、装备、位置与饵的收益 | 固定角色有效配置；可统计累计收益，但不自动消耗经验/金币改变配置 |
| B 完整成长 | 验证玩家从1级开始的成长曲线 | 模拟登录时购买、加点、换配置、解锁、重置、出售/收藏；离线仍遵守真实自动化限制 |
| C 极端压力 | 查找漏洞、边界及幂等问题 | 零余额、全锁仓库、超高属性、反复重置、失败刷经验、重复结算等 |

单次可追踪完整抽样及时间节点；长期用事件驱动时间推进。支持参数批量替换、固定随机种子、版本及配置快照、复现具体异常案例。固定模式与成长模式的累计经验/等级展示应避免混淆（不改变固定配置）。

## 3. 初始内容

使用07所列池塘+水库、12鱼、6常规竿+2特殊、4鱼线、6鱼饵、4体色配置、10成就、3事件模板的核心Demo预算。选择能覆盖小鱼/巨物、隐蔽/拉力、深度/远投、重量/体色、昼夜、共享/独有种群的配置。必要时增加仅用于测试的合成极端配置，不计入正式内容预算。

## 4. 玩家策略与活动矩阵

| 类型 | 目标 |
|---|---|
| 纯力量 | 全自由点投力量，巨物对抗 |
| 纯技巧 | 全投技巧，稳定捕获 |
| 纯敏捷 | 全投敏捷，主动操作效率 |
| 纯感知 | 全投感知，咬钩效率 |
| 纯幸运 | 全投幸运，稀有内容 |
| 均衡 | 五属性平均分配 |
| 经济流 | 动态配置，金币净收益最大化 |
| 升级流 | 动态配置，单位时间XP最大化 |
| 收藏流 | 动态配置，图鉴、体色、纪录目标 |

普通策略只能使用玩家可见信息、历史观察、失败反馈；理论最优可读取内部概率，寻找收益上限和漏洞。需区分纯属性策略的目标装备与固定相同装备对照，不把装备优势误归因属性。模拟器策略只是测试代理，不能成为正式游戏的离线自动加点、换装备、换地图功能。

登录频率：每天1、2、4次及高频极限玩家。广告习惯：从不、少量、使用大部分可用权益。必须有同策略、同登录频率的有/无广告对照，区别广告和活跃程度的影响。每日登录具体时刻及在线停留时长待定。时长以真实日历和实际有效作钓时长分别统计，不能一律假设每天24小时收益。

## 5. 时间及抽样规模

| 时间跨度 | 目的 |
|---|---|
| 10分钟 | 新手首次捕获、出售、升级 |
| 1小时 | 初始经济与首购 |
| 8小时 | 初始离线 |
| 24小时 | 日常收益 |
| 7天 | 中期成长 |
| 30天 | 主要内容推进 |
| 60天 | 收藏与巨物 |
| 180天 | 后期金币及属性收益 |
| 365天 | 无限等级及长期稳定 |

抽样规模建议：单次调试1个固定种子；日常调整100次；成长曲线1000次；低概率事件10000次以上按实际概率及置信精度确定；独立概率模型可百万级抽样。无需全矩阵均运行365天；低概率用专门抽样和解析概率对照。对比配置使用可复现种子，记录采样量及不确定性；未达成里程碑的样本单独标记，不可从统计中直接剔除。P10/P25/P50/P75/P90、均值、最小最大均输出；稀有事件同时输出发生比例。百分位含义与指标方向相关（越快越好的达成时间不等于越大越好）。

## 6. 六类数值验收

| 维度 | 初步目标（待模拟） |
|---|---|
| 新手 | 首捕约1分钟、首升级3～5分钟、首次成长装备10～30分钟、初始配置成功率90%以上、正净收益、初次离线无广告依赖 |
| 成长 | 第1天基础系统，第2～7天多地区与流派，第8～30天全部常规地区及大部分常规装备，第31～60天深度图鉴与收藏，60天后长期目标 |
| 属性 | 各属性存在有效优势场景；不能单属性垄断所有目标，极端加点可正常游玩 |
| 经济 | 基础饵正收益，普通付费饵适配时有价值，高级饵有专项价值；装备回本合理，重置封顶约成熟经济流2～4小时净收益；无死锁 |
| 随机收藏 | 普通玩家30天不应普遍完全见不到体色鱼，数天不应轻易集齐；稀有鱼与纪录保留长期价值；关键隐藏发现有合理周期 |
| 广告 | 无广告能获得全部主要内容、特殊竿及24h永久额度；收益明显但有限；无广告专属内容 |

正式首版5常规+1隐藏的成长目标不直接套用到仅2地区的Demo。验收前要明确对应玩家画像、登录频率、是否观看广告、目标百分位及允许误差。经济目标主要评价可行策略，不保证任意付费饵或任意配置盈利。后期金币积累不是失败条件。

## 7. 硬规则回归测试

以下不变量属于规则验收而非可通过调参放宽的数值目标。用可复现用例覆盖正向、反向和边界：

| ID | 场景 | 必须成立 |
|---|---|---|
| R01 | 极端加点与装备加成 | 属性先合并再递减，不越硬约束 |
| R02 | 距离/深度各自合格但联合线长不够 | 禁止位置准入，不自动换位置 |
| R03 | 环境及广告中途变化 | 保留等待/执行进度，仅分段调速 |
| R04 | 鱼饵零偏好、禁止鱼种、空候选池 | 不归一化非法权重，不强抽鱼；按空竿规则 |
| R05 | 权重归一化、零权重与环境上限 | 概率合法，总和为1（非空池）；禁止条件不复活 |
| R06 | 重量区间边界及最大值 | 整数克、等级互斥、最大值可达不超限 |
| R07 | 特殊体色、重量独立 | 条件分布独立，体色不影响捕获难度 |
| R08 | 极高力量/技巧但客观超载 | 必然失败，失败XP为0 |
| R09 | 临界负载+操作失误/高延展 | 合法缓冲及技巧收益，持续负载不被缓冲 |
| R10 | 多失败节点、加速或重登 | 最早失败唯一结算，必经节点不可跳过 |
| R11 | 故意失败、取消、极慢对抗 | 失败XP有上限可为0，取消0，不重复奖励 |
| R12 | 多级升级及离线升级 | 经验不丢、点数准确、会话额度锁定 |
| R13 | 金币不足及自动部分补货 | 不透支、不突破保留金币；执行预设备用 |
| R14 | 全仓锁定 | 不擅自出售锁定鱼，合法暂停/处理路径 |
| R15 | 自动卖、收藏、相同重量 | 正常图鉴经验，移动不重复奖励，同重不刷纪录 |
| R16 | 重置100次、免费/广告混合 | 金币费用递增封顶，免费不计次，点数守恒 |
| R17 | 预购饵、广告饵及离线广告 | 奖励基数扣实际消耗参考价，现金不重复扣，每会话一次 |
| R18 | 关键事件重复、软保底 | 唯一奖励、有效尝试、无稀有重量体色保底 |
| R19 | 在线/离线及分段推进一致性 | 相同状态与输入时间线结果一致 |
| R20 | 重复启动/结算、时钟回拨、异常恢复 | 本地单任务、已提交区间不重复发奖；跨设备及可信时间为P1，不宣称客户端强防作弊 |
| R21 | 新版本调整价格/分布 | 旧历史不被篡改，未售鱼按新定价，不追溯收益 |
| R22 | 365天极高属性及余额 | 无溢出、非法概率、负余额、无法继续结算 |

实现阶段补齐精确断言、随机种子、输入输出和覆盖率；正式部署前还要验证微信本地存档、广告客户端回调、版本迁移及平台兼容等非纯数值功能；云端能力按P1/P2另行验收。

## 8. 报告与诊断

每次模拟输出：角色等级/XP/属性/重置次数；金币净额/支出/鱼获价值/实际鱼饵成本；捕获数量/成功率/失败细分/耗时；装备购买/使用/回本；地区解锁时间/停留/位置；图鉴/体色/纪录/事件；广告次数及增量；有效挂机时间/额度损失/暂停；规则异常及对应输入、种子、配置版本。分离一次性奖励与稳态收益、成功个体与咬钩个体、日历时间与有效钓鱼时间。保留对照数据及可复现异常日志。

## 9. 迭代顺序

1. 建立初始数据配置及范围校验。
2. 独立验证八个模型及数学分布。
3. 验证一次完整钓鱼行为与状态机。
4. 调整初始成功率与耗时。
5. 调整经验与金币价值。
6. 调整五属性收益曲线及相对职责。
7. 调整装备价格、升级曲线与解锁。
8. 调整完整玩家成长及活跃差异。
9. 调整随机事件与收藏周期。
10. 调整广告收益与长期金币消耗。
11. 全面回归与长时压力测试。
12. 审查后冻结第一版数值基线。

每轮保存配置、代码/引擎版本、种子、测试矩阵及报告，不覆盖历史基线。硬规则不因调参擅自改变；如需变更，先提交规则修订。
