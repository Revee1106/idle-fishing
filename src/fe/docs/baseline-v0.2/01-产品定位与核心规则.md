# 01｜产品定位与核心规则

状态：已确认（明确标注的暂定项除外）。

## 1. 产品定位

面向男女老少的微信休闲挂机钓鱼小游戏，核心是低操作负担、持续成长、随机惊喜和收藏。玩家不需要手动抛竿、控制拉力或收线；玩家的价值在于制定策略，选择地区、位置、装备、鱼饵及角色加点。

- 竖屏、治愈插画风，具体UI交由其他AI设计。
- 单人玩法为主；不设置PVP、玩家交易、赠送或市场投机。
- 无内购，变现仅依靠自愿激励视频。
- 不依赖每日签到、日常任务、体力或强制在线来维持进度。
- 以真实鱼种为首版内容基础，虚构鱼种后续再考虑。

## 2. 核心循环

选择地区 → 选择鱼竿、鱼线、鱼饵 → 选择水平距离及垂直水层 → 校验准入与运行条件 → 自动抛竿 → 等待咬钩 → 抽鱼种及个体 → 收线对抗 → 捕获结果 → 经验、图鉴、纪录、成就、鱼获处理 → 准备下一次。

成功鱼获可以出售获得金币，也可手动放入水族馆收藏。金币用于装备、鱼饵、地区解锁、仓库与水族馆扩建、属性重置。升级得到自由属性点。探索地区、环境及随机事件带来新的鱼种、隐藏内容、特殊装备及收藏目标。

## 3. 设计原则

| 原则 | 具体含义 |
|---|---|
| 策略而非操作 | 玩家定目标及配置，自动执行完整钓鱼行为；不引入手动战斗小游戏 |
| 在线离线同规则 | 同一时间状态机、同一概率、消耗及收益；无离线折扣 |
| 成长不突破硬约束 | 属性再高也不能突破位置、物理承载、鱼种及重量候选边界 |
| 多策略有效 | 不要求各流派收益相等，但不得有一种属性或装备在所有目标下绝对最优 |
| 随机不阻断主线 | 常规地区稳定可达，不要求极低概率鱼获；隐藏内容可以随机发现 |
| 低惩罚 | 失败消耗时间及已用消耗型鱼饵，无装备损毁、维修或额外金币惩罚 |
| 无经济死锁 | 初始装备与免费基础饵永久可用，存在稳定正收益配置 |
| 长期不强制追赶 | 旧地区保留鱼种、纪录、经济、事件及收藏价值；无限等级不等于无限内容门槛 |
| 广告可选 | 不看广告仍可获得全部正常内容、特殊装备及永久24小时离线时长 |
| 收藏独立 | 收藏、纪录及成就不能成为持续属性或经济加成的强制系统 |

## 4. 玩家长期目标

前期：完成首次捕获、首次出售、升级、首次装备成长，理解位置及装备匹配。中期：解锁更多地区、形成属性流派、研究鱼饵与鱼线。后期：解锁全部常规地区及主要装备。长期：稀有鱼、特殊体色、纪录级重量、特殊鱼竿、隐藏探索、水族馆及无限等级。

主要成长内容约30天、收藏60天以上为初步设计目标，非已验证时长。允许玩家一直停留在偏好的地区，不以地区等级压制收益。

## 5. 首版不做的内容

手动收线或实时操作战斗、体力、装备强化和耐久维修、强制任务/签到、私人鱼塘、鱼类喂养繁殖生病死亡、水族馆经营收益、内购、玩家交易、PVP、动态市场、地区入场或停留费用。好友访问、排行、周期比赛、奖杯室、装备改装属于后续扩展，不能成为首版依赖。
