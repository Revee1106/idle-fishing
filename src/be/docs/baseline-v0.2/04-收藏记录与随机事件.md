# 04｜收藏、纪录、成就、水族馆与随机事件

## 1. 图鉴

鱼种是全局对象，地区发现是独立记录。同一鱼种跨地区不重复成为新鱼种。普通未发现鱼可展示剪影及部分习性提示，完全隐藏鱼种不提前展示；不公开精确概率。

成功捕获后更新图鉴、首次时间及重量、累计数量和重量、最大/最小/平均重量、已发现体色、地区/位置、鱼饵/时间/习性等记录。失败不揭示精确重量或解锁成功图鉴；出售不删除发现历史。支持按鱼种、地区、稀有度、体色等筛选。

## 2. 纪录

维护全局最大/最小重量、每鱼种最大/最小、体色纪录、地区纪录、鱼种×地区纪录。刷新记录应保存必要的完整历史：个体、重量、体色、时间、地区位置、天气事件、装备鱼饵、角色等级和有效属性、版本。相同重量不刷新，首次达成时间保留，可统计同重量纪录鱼次数。纪录不提供永久属性或独立售价倍率；额外经验遵循05、06。

鱼个体重量与体色永久锁定；每个个体有唯一ID。仓库、水族馆中的鱼保留完整数据，首次/纪录/重要事件保留必要或完整档案，普通已售鱼汇总后允许清理明细。

## 3. 成就

类型包含生涯、巨物、图鉴、地区、装备/特殊挑战、趣味、隐藏；支持阶段性、一次性、隐藏成就。条件由统一统计与组合判定实现，奖励唯一发放。奖励可为金币、鱼饵、普通/特殊装备、经验（可配置）、称号、头像框、装饰、特殊地区发现/资格；无永久属性增益，不设置广告专属成就。日常/周常/签到不是首版核心。

## 4. 私人水族馆

只展示玩家实际成功捕获并手动放入的鱼，支持多鱼缸、淡水/海水生态类型、最大单体规格及总展示空间（按个体大小占用而非简单数量）。玩家可购买、扩展、转移鱼、取回仓库或出售；生态和空间约束必须满足。鱼可游动并查看捕获档案，自定义名称、装饰槽、背景主题按P1计划。收藏不要求集齐所有鱼，不设置必须追求的综合评分。

不喂食、不繁殖、不成长、不生病、不死亡、无维护成本、无金币经验属性产出，不自动将鱼放入水族馆。无私人鱼塘。好友访问、排行榜、周期比赛和奖杯室后续再做，不引入玩家间赠送或交易。

## 5. 四类随机事件

| 类别 | 作用 | 例子 |
|---|---|---|
| 环境事件 | 区域/位置/鱼种作用域；在游戏时间内临时修改生态 | 聚集、巨物出没、洄游、特殊体色鱼群、沉寂 |
| 意外鱼获 | 替代正常鱼或作为额外奖励 | 漂流瓶、宝箱、遗失钓具、钱币 |
| 探索事件 | 直接发现或多阶段线索；永久解锁目标 | 隐秘地图、隐藏位置、特殊钓具线索 |
| 特殊遭遇 | 普通钓鱼中的稀有个体特殊表现 | 巨物或罕见鱼遭遇，不额外抽第二条鱼 |

环境事件不受个人幸运直接影响；同类型不重复叠加、不同类型有整体倍率上限；昼夜、天气、事件效果独立配置，不能无差别重复放大所有模型。洄游可以显式添加临时鱼种候选。

个人意外事件由幸运等合法条件有限修正。替代型在咬钩节点、鱼种抽取前判定，符合条件的总触发概率有上限，每次至多一个；额外型在行为结算按各自条件判定（必要时要求成功）。替代型仍消耗已用鱼饵，不生成鱼类个体；宝箱自动打开，金币、鱼饵、装备、线索等自动入对应系统，不占鱼获仓库。不通过主动取消或故意无效失败刷奖励。

## 6. 隐藏探索与特殊鱼竿

事件条件可包含地区、位置、昼夜、天气、等级、鱼饵、有效尝试次数、前置发现。发现可直接解锁，也可形成多阶段线索；不引入复杂强制任务。隐藏区域/位置发现后仍须正常装备准入。常规成长路线不依赖隐藏发现，不形成循环前置条件。

允许对关键一次性地图、线索和部分特殊鱼竿设置隐藏软保底，累计有效尝试、跨登录保留，条件和上限独立配置。不对稀有鱼种、重量、体色或纪录设保底。特殊鱼竿唯一，重复取得转换普通奖励；不能以广告或商店直接获得。特殊竿不必拥有幸运，也不必须优于普通竿。

特殊遭遇使用同一个已生成个体与正常捕获规则，失败不解锁其成功图鉴或精确重量。离线事件按时间顺序处理，自动发放/解锁，不能自动切换地区或装备；重要发现永久记入探索日志，普通事件汇总即可。

## 7. 分享及后续社交

P1可考虑主动分享鱼获卡片、纪录、图鉴进度，不强制分享。好友访问、排行、周期比赛与奖杯室P2，未来需独立评估广告与比赛公平性；不把广告作为直接比赛分数来源。
