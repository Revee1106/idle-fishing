# 02｜角色、装备与地区生态

状态：职责和约束已确认；具体配置、名称和数值暂定。

## 1. 角色属性

角色1级开始，无等级硬上限。每级固定发放自由属性点，不自动增加五项属性。玩家可以保留属性点、批量分配或重置全部已分配点。五项初始属性各10、每级5点仅作为模拟起点。有效属性=初始+自由加点+当前鱼竿加成；不得对各来源分别计算边际收益后相加。

| 属性 | 正向职责 | 不直接影响 |
|---|---|---|
| 力量 | 持续对抗、力量不足风险、额外挣扎时间 | 装备额定承载、位置准入、鱼种概率 |
| 技巧 | 脱钩、操作失误引起的超载风险 | 客观负载、等待、直接缩短对抗时间 |
| 敏捷 | 抛竿、基础收线、重新准备 | 咬钩等待、捕获成功率 |
| 感知 | 咬钩等待速率 | 单次鱼种相对概率、成功率 |
| 幸运 | 稀有鱼种、重量等级、特殊体色、个人价值事件 | 等待、捕获风险、售价、硬性边界 |

无单项硬上限，允许极端加点。属性效果边际递减，不设置职业、属性转换、百分比装备属性加成、成就永久属性或等级压制。分配及重置对下一次抛竿生效。重置详见06。

## 2. 鱼竿

物理性能与角色加成独立配置。物理性能包括承载强度（N）、控鱼能力、灵敏度、收线效率、最大抛投距离（m）、最大作钓深度（m）。类型包含轻型、综合、重型、远投、深水等。

同类型高品质通常性能更好，但跨类型有取舍；品质标签不直接参加公式。普通鱼竿可加力量、技巧、敏捷、感知，禁止加幸运；部分特殊鱼竿可以加幸运，但不要求所有特殊鱼竿有幸运，也不保证全面优于普通竿。仅装备中的一根生效，不累计持有加成。

特殊鱼竿来自特定成就、挑战、随机事件、隐藏探索，未来可来自比赛；不通过商店、广告、内购直接获得。普通装备可由商店、地区商店、成就或事件提供。允许按等级及地区解锁购买或使用资格，不必逐级购买前置装备。已拥有装备永久保留，不重复购买、不出售、不丢弃、不强化、不维修；失败不损装备。后续改装可考虑，但非首版。

## 3. 鱼线

独立配置额定拉力（N）、隐蔽性、延展缓冲、信号传递、总长度和有效长度（m）。有效长度需覆盖作钓水平距离与垂直深度的联合需求，预留比例暂定10%。材料候选为尼龙、编织、碳素：分别强调均衡/缓冲、拉力/信号、隐蔽性；规格可存在粗细和长短取舍，不仅是纵向升级。额定拉力与鱼竿额定承载分别校验。

## 4. 鱼饵

每种鱼饵独立配置基础吸引力（等待）、鱼种偏好（相对分布）、重量偏好（重量区间）、价格及消耗类型。鱼饵的三个效果不得混用。鱼种偏好为0时该鱼种不可出现，幸运不能突破。重量偏好为0时对应区间不可出现。

免费基础饵无限，不需要广告；必须有稳定可捕获鱼类及正收益配置。普通消耗型鱼饵抛竿时扣除，成功、失败、空竿或取消均不退。可重复拟饵一次性取得，使用不消耗数量。鱼饵按解锁规则购买，取得后不强制限定地区；以当地鱼种适配判断。高级鱼饵不全面替代普通鱼饵，可为了目标鱼、巨物或探索而接受亏损。

偏好配置支持默认→食性分类→鱼种覆盖→可选地区覆盖；后者替换前者而非全部叠乘。正式游戏不展示精确概率，只展示习性、偏好、已知位置等信息。

## 5. 地区与位置

世界→地区→作钓位置；不增加独立寻路地图。地区准入与位置准入分开。地区解锁可以要求等级、金币、图鉴进度、纪录、发现等；常规地区分支解锁，隐藏地区通过探索，不作为普通地区必须前置。地区切换免费、即时、次数不限，同时只存在一个有效作钓任务。各地区保存上次配置；离线不自动切换。

每个位置以独立ID描述水平分类（近/中/远）和垂直分类（浅/中/深）、实际米数、所属地区、是否隐藏及存在性。并非所有距离和水层都能组合。玩家主动选择位置，装备不足不自动换位置。隐藏位置发现和装备准入分别判断。

地区物理位置不因昼夜或天气改变；鱼群洄游等事件允许临时修改鱼种分布，不改变装备硬性准入。鱼类种群不设有限库存或钓光机制。

## 6. 首版地区定位

| 地区 | 主要特征 | 解锁方向（具体阈值待定） |
|---|---|---|
| 乡间池塘 | 初始、低成本、稳定经济、普通鱼纪录 | 默认开放 |
| 山间溪流 | 小鱼效率、警觉性、轻型装备 | 等级 |
| 大型水库 | 巨物、远投、深水、装备承载 | 等级+一次性金币 |
| 热带河流 | 独有淡水鱼、鱼饵与习性差异 | 等级+图鉴进度 |
| 近海海岸 | 海水生态、远投及鱼线搭配 | 等级+一次性金币 |
| 隐秘山湖 | 隐藏鱼种、特殊体色、探索 | 隐藏地图/发现 |

热带河流与近海海岸不要求完成水库的全部内容。不同地区至少有一定独有内容；同一真实鱼种可共享合理生态分布。旧地区长期有价值。淡水竿不因名称而不能海钓，按物理准入和捕获性能判定。

## 7. 鱼类数据的三层模型

| 层级 | 数据职责 |
|---|---|
| 鱼种 | 全局ID、稀有度、理论最小/最大重量、参考重量、重量区间及分布、持续挣扎/爆发/脱钩、警觉性、活跃度、鱼饵偏好、经验、基础售价、允许体色、习性 |
| 种群 | 地区及位置关联、基础分布权重、活跃度、重量及体色修正、环境偏好和临时分布 |
| 个体 | 唯一ID、鱼种、整数克重量、重量等级、体色、捕获时的配置/环境/时间/版本等档案、归属 |

同鱼种共享理论重量硬边界；当地分布可限制某些重量或体色。全局稀有度（普通、少见、稀有、珍稀、传说）不等于当地概率。重量等级（微型、小型、普通、大型、巨型、纪录级）与鱼种稀有度独立。特殊体色单一、独立生成，不影响对抗、不作为新鱼种。相同鱼种及重量具有相同基础对抗属性。

## 8. 世界时间与环境

现实2小时=游戏24小时（12倍世界时钟）；钓鱼动作、离线额度、广告时长等使用现实时间。每个地区有独立天气、鱼群活跃度及环境事件；昼夜/天气可以改变咬钩频率、相对鱼种分布、重量及体色权重，具体效果独立配置。无天气强制停钓、损坏装备等惩罚。环境事件与个人幸运事件分开，环境事件不受个人幸运直接影响。
