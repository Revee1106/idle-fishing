# Frontend Development Rules

前端 AI 负责 Cocos Creator 客户端、UI、交互、资源管理、屏幕适配、动画、微信文件系统/生命周期/广告 SDK 适配、构建和真机验证。

所有正式业务操作必须通过公共 ApplicationApi；业务数据通过 ReadApi 或正式状态订阅接口读取。
前端不得直接修改金币、经验、等级、鱼获、属性、装备和解锁状态。
前端不得自行实现鱼类概率、捕获判定、价格、经验或离线收益算法。
禁止复制后端核心业务实现。

后端接口未完成时允许使用符合公共契约的 Mock。Mock 仅用于开发测试，必须与正式实现隔离，不得成为独立业务规则引擎，正式发布构建不得启用 Mock。

接口无法满足页面需求时，记录缺失接口及场景并等待设计方确认，不得自行修改公共接口。
